全景视频智能跟踪赛道
赛题题目
面向 360° 全景视频的实时单目标跟踪
题目描述
全景相机一次拍摄即可记录周身 360° 的全部视野，“先记录、后取景”——拍摄时无需瞄准，后期再决定看向哪里。但这也带来一个新问题：一段全景视频里绝大部分视野是冗余的，用户真正关心的往往只是其中某个运动的主体。要把全景素材变成一段"始终对着主体"的可看视频，前提是系统能在整段视频里自动、持续地知道目标在球面上的位置，这正是全景视频目标跟踪要解决的问题。
与常规平面视频跟踪不同，全景视频以等距柱状投影（Equirectangular）存储 360°×180° 的球面信息，这带来了一系列独有的技术挑战。在实际的全景纯视觉跟踪场景中，传统方案存在以下痛点：
1.投影畸变导致特征失真：等距柱状图在两极附近被严重拉伸，同一目标在赤道和高纬度区域的形状、尺度差异巨大，普通检测/跟踪模型难以直接适应这种非均匀畸变。
2.目标跨越经线边界：目标在 360° 环形空间中运动时会从图像最右侧"穿越"到最左侧，坐标发生跳变，常规基于连续坐标的运动模型会在此处失效。
3.极点奇异性：当目标运动到接近正上/正下方（pitch ≈ ±90°）时，偏航角（yaw）失去意义，目标形变剧烈，跟踪容易出现漂移或丢失。
4.长期跟踪与目标找回：全景视野极大，目标可能被遮挡、离开子视野后又重新出现，跟踪器需要在漂移与丢失之间做出判断，并在全 360° 空间内高效地重新找回目标。
5.实时性约束：全景图分辨率高、信息量大，整套跟踪系统需在端侧算力约束下实时运行。

为解决以上痛点，本题目期望参赛者基于轻量级视觉模型，搭配高效的搜索与后处理策略，在全景视频上完成对指定目标的精准、稳定、实时的跟踪。
本题目将重点解决以下核心挑战：
1.全景畸变下的准确跟踪：在 360° 球面成像的强非均匀畸变下，实现对指定目标的准确定位，在赤道与高纬度区域、目标尺度剧烈变化时均保持较高的跟踪成功率。
2.长时跟踪的稳定性与找回能力：面对遮挡、目标短暂离开视野、相似目标干扰等长时跟踪难题，保证跟踪不漂移、不误跟；目标丢失后能够重新捕获，兼顾找回的成功率与及时性。
3.低算力下的高效实时推理：在保证跟踪精度的前提下，面向端侧受限算力平台优化模型与推理流程，将单帧端到端处理控制在实时可用的水平。
具体要求
1.全景单目标跟踪方案设计：构建从"全景视频 + 初始目标框"到"逐帧目标位置（跟踪框）"的完整算法流程。
2.比赛提交方式：参赛选手将算法封装成docker镜像，上传到测评网站做自动化评分。
3.比赛评分方式：
a.初赛：精度指标排名，选取TOPN个指标最佳队伍进入决赛
b.决赛：精度指标、算法运行帧率、方案设计答辩 综合评测
评测指标说明
评测采用目标跟踪领域通用的 OTB 协议，以跟踪框与标注框的交并比（IoU）为基础衡量跟踪质量。对第 i 帧，其跟踪框 Bi 与真值框 Gi 的交并比定义为：
IoUi=|Bi∩Gi||Bi∪Gi|
给定一个成功阈值 t，若某帧满足 IoUi>t，则记为一次成功跟踪。在全部有效帧上，成功帧所占比例即为该阈值下的成功率：
S(t)=1Ni=1N1IoUi>t
将阈值 t 从 0 到 1 以步长 0.05 取值（共 21 个采样点），得到成功率随阈值变化的曲线，即成功率曲线（Success Plot）。据此定义两个主要指标：
•Success Rate：阈值 t=0.5 时的成功率 S(0.5)，即 IoU 大于 0.5 的帧所占比例。
•AUC（曲线下面积）：成功率曲线在全阈值上的平均值，反映整体跟踪质量：
AUC=121k=020S(0.05k)
