# InstaTargetingSystem 几何规范

> 本文档定义 360VOT 风格的球面几何、局部视图裁剪和回投影规则。  
> 几何层只处理坐标和采样，不做跟踪决策。

---

## 1. 职责边界

| 输入 | 输出 | 不负责 |
|------|------|--------|
| ERP 帧、初始框、BFoV 请求 | 局部视图、球面框、回投影框 | 模型置信度、状态机、模板更新 |
| 局部视图、局部框 | 球面 BFoV | 目标重识别 |
| 可选深度图 | 同视角深度裁剪 | 深度运动判断 |

几何层的目标是把全景图变成 HiT 能看懂的低畸变局部图，再把局部结果转回球面表示。
深度增强不属于本层：geometry 只同步裁剪原始 Depth，深度归一化、边缘预测和 RGB 改色
由 `TrackerBackend` 完成，避免几何层与模型输入耦合。

---

## 2. 核心表示

| 类型 | 含义 |
|------|------|
| `BBoxXYWH` | 像素框，`x, y, width, height` |
| `SphericalPoint` | 球面中心点，含 `yawRad` 和 `pitchRad` |
| `BFoV` | 球面视场，含中心、水平 FOV、垂直 FOV、滚转 |
| `ViewSpec` | 一个局部视图的规格 |
| `LocalView` | 某个 `ViewSpec` 下裁出的图像和可选深度 |

`geometry` 内部以弧度和单位球向量为准。`yaw` 只用于显示和序列化，不作为跨经线
连续性判断的唯一依据。

ERP 采样按像素边界解释，局部裁剪按像素中心取样。默认边界采样预算由
`geometry.boundarySamplesPerEdge` 控制，当前实现建议值为 65。

---

## 3. 主要变换

### 3.1 `bboxToBfov()`

把 ERP 上的框转成球面中心和视场。该函数用于首帧初始化和回投影后的结果规范化。

### 3.2 `cropViews()`

按 `ViewSpec` 列表从 ERP 帧裁出一个或多个局部透视图。要求：

- 保持 `specs` 顺序。
- 水平方向循环采样。
- 垂直方向钳制边界。
- 若输入带深度，局部视图应携带同视角深度裁剪。
- 输出顺序、`viewId` 和 `ViewSpec` 必须一一对应，允许 DTC 在同一帧请求多张视图。
- RGB 和 Depth 必须共享同一个 BFoV、输出尺寸和采样坐标；Depth 缺失时返回 `None`，不得填零。

### 3.3 `localBoxToBfov()`

把 HiT 在局部视图中的输出框转回球面视场。回投影时采样边界，不只取四角。

### 3.4 `bfovToBbox()`

把球面视场转回 ERP 框，用于输出与评测。

---

## 4. 采样规则

1. ERP 横轴对应经度，纵轴对应纬度。
2. 横向可跨经线，纵向不可循环。
3. 近极点区域优先增密边界采样。
4. 大视场框必须做边界采样，避免只看四角造成误差。

---

## 5. 输出约束

- 几何层不生成跟踪状态。
- 几何层不计算模板命令。
- 几何层不读取模型权重。
- 几何层返回的数值必须可被 `interface.md` 中的 `SphericalGeometry` 直接消费。

### 5.1 DTC V2 视图约束

DTC 按状态请求视图：稳定/不确定状态为主视图加四个切平面角保护视图，恢复状态为球面环，
丢失扫描为四个赤道面和南北极面的六面 cube-map。geometry 只按 `ViewSpec` 裁剪，不判断视图
可信度。上下文目标宽高至少各为初始框和最近可靠框对应尺寸的 `contextScale` 倍，并叠加运动
不确定度；超过 `maxFov` 时钳制。大搜索 FOV 不等于最终输出框大小。

---

## 6. 接口对齐

本几何文档对应 `interface.md` 中的：

- `SphericalGeometry`
- `ViewSpec`
- `LocalView`
- `bboxToBfov()`
- `cropViews()`
- `localBoxToBfov()`
- `bfovToBbox()`

`geometry` 是 `DTC` 和 `HiT` 之间的中间层，不持有状态机。
