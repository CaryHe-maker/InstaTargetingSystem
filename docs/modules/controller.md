# InstaTargetingSystem 控制器规范

> 本文档定义 DepthAwareTrackController，简称 DTC。
> DTC 负责把几何结果、HiT 输出和深度信息合并成可执行的跟踪决策。

---

## 1. 职责边界

| 输入 | 输出 | 不负责 |
|------|------|--------|
| 帧、深度摘要、局部观测、运动状态 | 搜索计划、模板命令、跟踪结果 | 图像裁剪、模型推理、文件 I/O |

DTC 是控制层唯一有状态模块。它持有状态机、深度门控、运动估计和模板更新规则。
`T0` 线程只通过 DTC 做逐帧决策。

---

## 2. 状态机

```text
INIT -> TRACKING -> UNCERTAIN -> RECOVERING -> TRACKING
                       |             |
                       +-----------> LOST
                                      |
                                      +-> RECOVERING
```

| 状态 | 动作 | 模板更新 |
|------|------|----------|
| `INIT` | 建立首帧模板和初始运动状态 | 只初始化 |
| `TRACKING` | 单视图跟踪 | 允许稳定更新 |
| `UNCERTAIN` | 扩窗验证 | 禁止 |
| `RECOVERING` | 环搜或全景粗搜 | 禁止 |
| `LOST` | 降频搜索并输出预测 | 禁止 |

状态转移只由 `DTC` 决定，不由 `HiT` 或 `geometry` 直接驱动。

---

## 3. 处理流程

### 3.1 初始化

1. 读取首帧和初始框。
2. 通过几何层生成首个模板视图。
3. 用深度摘要记录初始距离。
4. 生成初始 `MotionState3D`。
5. 提交首帧结果并进入 `TRACKING`。

### 3.2 正常跟踪

1. 读取上一次可信状态。
2. 结合深度和运动状态预测下一位置。
3. 向几何层请求一个主搜索视图。
4. 接收 HiT 的局部观测。
5. 计算融合分数并更新状态。

### 3.3 恢复

1. 若置信度下降，进入 `UNCERTAIN`。
2. 若连续低置信，进入 `RECOVERING`。
3. 触发扩窗、环搜或全景粗搜。
4. 通过外观、运动和深度三类门限确认目标。
5. 找回成功后回到 `TRACKING`，但不立即覆盖首帧模板。

---

## 4. 深度规则

### 4.1 深度摘要

DTC 只消费深度摘要，不直接依赖整张深度图作为主输入。深度摘要至少包括：

- 中位深度
- 平均深度
- 有效比例
- 最小深度
- 最大深度
- 深度置信度

### 4.2 深度用途

- 估计目标远近变化。
- 调整搜索窗口大小。
- 抑制明显不合理的找回候选。
- 辅助模板更新门控。

### 4.3 深度禁区

- 深度不作为唯一定位依据。
- 深度缺失时 DTC 必须退化为 RGB + 球面几何。
- 深度跳变过大时禁止直接更新稳定模板。

## 5. 与接口的对应

| 文档对象 | DTC 角色 |
|----------|----------|
| `TrackController` | 对外控制器协议 |
| `SearchPlan` | 搜索计划 |
| `InitializationPlan` | 首帧初始化计划 |
| `ProjectedObservation` | 统一后的局部观测 |
| `MotionEstimator` | 运动预测器 |
| `DepthProcessor` | 深度摘要器 |

DTC 的实现必须和 `interface.md` 的方法签名一致，不能自行增加新的状态提交入口。

---

## 6. 模板策略

- 首帧模板只读。
- 稳定模板仅在连续高置信时更新。
- 近期模板用于外观缓变。
- `UNCERTAIN`、`RECOVERING`、`LOST` 禁止更新。

模板污染优先视为控制层错误，不交给 `HiT` 修复。

---

## 7. 失败处理

1. 若 `HiT` 无有效观测，保持预测态。
2. 若深度无效，降低深度权重。
3. 若多个候选分数接近，优先保留运动连续性更好的候选。
4. 若连续找回失败，进入 `LOST` 并降频全景搜索。

---

本控制器文档对应 `interface.md` 中的：

- `TrackController`
- `SearchPlan`
- `InitializationPlan`
- `ProjectedObservation`
- `MotionEstimator`
- `DepthProcessor`
